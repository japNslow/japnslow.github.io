## 📌 Классификация проектов и авторство

### 👑 Авторские проекты Миши (написаны с нуля)
- **[KirillOS v0.2](https://github.com/japNslow/KirillOS)** — Собственная 32-битная монолитная ОС для x86 Protected Mode. Загрузчик kboot (MBR), дисковая ФС KirillFS на ATA PIO, графический режим VGA Mode 13h (320x200 256 цветов напрямую через регистры CRTC/Sequencer), аудиодрайвер Intel AC'97 с DMA bus-mastering и PC Speaker, двухпанельный hex-редактор секторов диска Kdhe, текстовый редактор Kano (клон nano), музыкальный трекер Kmidi и компилятор KHEXD языка K.
- **[64-raycasting](https://github.com/japNslow/64-raycasting)** — 3D Raycasting движок для компьютера Commodore 64 (MOS 6510 @ 1.0 MHz, 64 KB RAM) в растровом режиме 160x200 Multicolor Bitmap с текстурами стен DOOM (стальная броня, заклепки, гермодвери), перспективным полом и управлением джойстиком Port 2.
- **[doom-ios-port](https://github.com/japNslow/doom-ios-port)** — Нативная адаптация и порт DOOM Classic под iOS (C++, C, Objective-C) со сборкой готового пакета `Doom.ipa` (11 МБ).
- **[AppleII-webemu](https://github.com/japNslow/AppleII-webemu)** — Браузерный эмулятор Apple II на чистом JavaScript и HTML5 Canvas с потактовой эмуляцией MOS 6502, видеорежимов Hi-Res/Lo-Res и поддержкой дисковода Disk II.
- **[kymis-puzzle](https://github.com/japNslow/kymis-puzzle)** — Авторская веб-игра: пятнашки 3x3 со стилизацией и наградой в виде выпитых литров кумыса (гарантированная 100% разрешимость поля).
- **[game](https://github.com/japNslow/game)** — Авторская мини-игра на экстремальную скорость реакции (5 кликов за 3 секунды).
- **[bk0010-emulator](https://github.com/japNslow/bk0010-emulator)** — Инициализированный концепт авторского эмулятора советского 16-битного ПК «Электроника БК-0010».

### 🇷🇺 Русская локализация (перевод Миши)
- **[learn-gdscript](https://github.com/japNslow/learn-gdscript)** — Форк популярного интерактивного учебного курса от GDQuest по языку **GDScript (Godot Engine 4)**. **Миша полностью перевёл весь курс на русский язык**: все теоретические уроки, практические интерактивные задачи, подсказки и UI. Интегрировал переводы в движок через TranslationManager Godot 4 и настроил CI/CD деплой веб-версии на GitHub Pages!
  - Онлайн-версия: [https://japnslow.github.io/learn-gdscript/](https://japnslow.github.io/learn-gdscript/)
