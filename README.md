## 🌟 Основные разделы портала

1. **🌐 Сборник всех GitHub Pages проектов**:
   - [AppleII-webemu](https://japnslow.github.io/AppleII-webemu/) — Полноценный браузерный эмулятор Apple II на Canvas и JS (эмуляция MOS 6502).
   - [learn-gdscript](https://japnslow.github.io/learn-gdscript/) — Интерактивный онлайн-учебник по языку GDScript (Godot 4).
   - [kymis-puzzle](https://japnslow.github.io/kymis-puzzle/) — Пятнашки 3x3 с кумысом («Кумыс Пазл»).
   - [game](https://japnslow.github.io/game/) — Реактивный кликер на 3 секунды.
   - [zcb3](https://japnslow.github.io/zcb3/) — Веб-страница кликбота Geometry Dash на Rust.
   - *Встроенное модальное окно быстрого предпросмотра прямо на сайте без перехода.*

2. **⚡ Флагманы и передовые проекты**:
   - **KirillOS v0.2** — Собственная 32-битная монолитная ОС для x86 Protected Mode с загрузчиком kboot (MBR), VGA Mode 13h (320x200 256 цветов напрямую через регистры CRTC/Sequencer), файловой системой KirillFS, Hex-редактором Kdhe, трекером Kmidi с AC'97/PC Speaker, текстовым редактором Kano и компилятором языка K!
   - **64-raycasting** — 3D Raycasting движок в графическом режиме 160x200 Multicolor Bitmap для Commodore 64 (MOS 6510 @ 1.0 MHz) с DOOM-текстурами и поддержкой джойстика.
   - **doom-ios-port** — Нативный порт классического DOOM для iOS (C++, C, Objective-C) со сборкой `Doom.ipa`.
   - **AppleII-webemu** — Веб-эмулятор винтажного Apple II на JavaScript Canvas.
