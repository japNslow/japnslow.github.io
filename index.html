KirillOS v0.2

32-Bit Monolithic Operating System for x86 (IA-32 Protected Mode)
👑 Авторская ОС Миши

Полноценная 32-битная монолитная операционная система, написанная Мишей с чистого листа на языке Си и ассемблере x86. Работает в Protected Mode без использования BIOS и внешних библиотек. Система имеет собственный двухстадийный загрузчик MBR, терминал kboot>, дисковую файловую систему KirillFS для ATA-накопителей, аппаратные прерывания клавиатуры (IRQ1 через IDT и PIC 8259A), графический режим VGA Mode 13h (320x200, 256 цветов напрямую через регистры CRTC/Sequencer), аудиодрайвер Intel AC'97 с поддержкой DMA Bus-Mastering и PC Speaker, интерактивный двухпанельный hex-редактор Kdhe с прямой записью секторов LBA диска, текстовый редактор Kano (полноценный клон GNU nano с аппаратным курсором), музыкальный трекер Kmidi с виртуальной клавиатурой фортепиано, системную утилиту kfetch и собственный двухстадийный компилятор KHEXD языка K!

✦
Собственный загрузчик kboot (MBR) Переход в 32-bit Protected Mode, IDT прерывания клавиатуры (IRQ1), загрузчик исполняемых файлов ELF32.
✦
VGA Mode 13h (320x200x256) Прямое программирование регистров VGA без BIOS, линейный фреймбуфер 0xA0000, алгоритм Брезенхема.
✦
Файловая система KirillFS До 32 файлов с хранением на ATA PIO жестком диске (LBA 321) или прозрачным RAM-фоллбэком.
✦
Музыкальный трекер Kmidi 2-октавное пианино, пошаговый секвенсор, воспроизведение через AC'97 DMA и PC Speaker (Марио, Тетрис).
✦
Редакторы Kano & Kdhe Полноценный клон nano с буфером строк, поиском Ctrl+W и двухпанельный hex-редактор секторов диска.
✦
Компилятор KHEXD Собственный язык K: двухстадийная трансляция в байт-код .khex и исполнение в виртуальной машине.

64-raycasting

3D Multicolor Bitmap Raycasting Engine for Commodore 64
👑 Авторский 3D движок

Собственный 3D движок Миши для легендарного компьютера Commodore 64 (процессор MOS 6510 на тактовой частоте 1.0 МГц и всего 64 КБ памяти). Движок полностью отказался от текстовых символов PETSCII в пользу настоящего растрового графического режима 160x200 Multicolor Bitmap Mode с попиксельной отрисовкой в видеопамять чипа VIC-II, текстурами стен из DOOM и Wolfenstein 3D (стальные бронелисты, заклепки, замковый камень с золотым медальоном, шлюзовые гермодвери), перспективным текстурированным полом, затенением по осям X/Y и управлением с джойстика в Port 2!

MOS 6510 (1 MHz) Commodore 64 160x200 Multicolor Bitmap DOOM Textures Port 2 Joystick C / Python Tables

doom-ios-port

DOOM Classic Native iOS Port & Tooling
👑 Авторская адаптация

Сборка и нативный порт классического движка id Software DOOM под мобильную операционную систему Apple iOS на C++, C и Objective-C. Миша адаптировал исходный код движка под требования современных компиляторов и iOS SDK, подготовил инструменты конвертации ресурсов и собрал готовый к установке пакет приложения Doom.ipa (11 МБ).

C++ (5 MB) C (700 KB) Objective-C Doom.ipa iOS Engine

AppleII-webemu

Apple II Vintage Computer Web Emulator (JavaScript Canvas)
👑 Авторский эмулятор // Live

Собственный браузерный эмулятор культового микрокомпьютера Apple II на чистом JavaScript и HTML5 Canvas. Потактовая эмуляция микропроцессора MOS 6502, цветные видеорежимы Hi-Res и Lo-Res на Canvas, эмуляция контроллера дисковода Disk II с возможностью монтирования .dsk образов и динамика. Запущен прямо в браузере на GitHub Pages!
