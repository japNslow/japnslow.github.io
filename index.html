KirillOS v0.2

32-Bit Monolithic Operating System for x86 (IA-32 Protected Mode)
🔥 Главный шедевр

Полноценная операционная система, написанная с нуля на языке Си и ассемблере x86. Включает собственный двухстадийный загрузчик MBR, терминал kboot>, файловую систему KirillFS для ATA-накопителей, мощный графический режим VGA Mode 13h (320x200 256 цветов напрямую через регистры CRTC/Sequencer), аудио-подсистему Intel AC'97 с DMA bus-mastering, двухпанельный hex-редактор Kdhe с прямой записью секторов LBA, клона GNU nano (Kano) и собственный компилятор языка K!

✦
Загрузчик kboot (MBR) Переход в 32-bit Protected Mode, IDT прерывания клавиатуры (IRQ1), загрузчик ELF32.
✦
VGA Mode 13h (320x200x256) Прямое программирование регистров VGA без BIOS, линейный фреймбуфер 0xA0000, алгоритм Брезенхема.
✦
Файловая система KirillFS До 32 файлов с хранением на ATA PIO жестком диске или прозрачным RAM-фоллбэком.
✦
Музыкальный трекер Kmidi 2-октавное пианино, воспроизведение нот через AC'97 DMA и PC Speaker (Марио, Тетрис).
✦
Редактор Kano & Hex Kdhe Полноценный клон nano с буфером строк, поиском Ctrl+W и hex-редактор секторов диска.
✦
Компилятор KHEXD Собственный компилятор языка K: трансляция в байт-код .khex и запуск в виртуальной машине.

64-raycasting

3D Multicolor Bitmap Raycasting Engine for Commodore 64
Retro 3D Tech

Рейкастинг-движок нового поколения для легендарного ретро-компьютера Commodore 64 (процессор MOS 6510 на тактовой частоте всего 1.0 МГц и 64 КБ ОЗУ). Движок полностью отказался от текстовых символов PETSCII в пользу настоящего растрового графического режима 160x200 Multicolor Bitmap Mode с попиксельной отрисовкой в видеопамять VIC-II, текстурами стен из DOOM и Wolfenstein 3D (стальные бронелисты, заклепки, замковый камень с золотым крестом, шлюзовые гермодвери), перспективным текстурированным полом, затенением по осям X/Y и управлением с джойстика!

MOS 6510 (1 MHz) Commodore 64 160x200 Multicolor Bitmap DOOM Textures Port 2 Joystick C / Python Tables

DOOM Classic Native iOS Port & Tooling
Classic Port

AppleII-webemu

Apple II Vintage Computer Web Emulator (JavaScript Canvas)
🌐 Live на Pages

Чистая реализация эмулятора легендарного компьютера Apple II в браузере. Полная программная эмуляция микропроцессора MOS 6502 с потактовой точностью, цветные видеорежимы Hi-Res и Lo-Res на HTML5 Canvas, поддержка эмуляции контроллера дисковода Disk II и динамика. Запущен прямо в браузере!

JavaScript (105 KB) HTML5 Canvas MOS 6502 CPU Apple II Architecture
